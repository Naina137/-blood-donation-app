## 🌟 What is LifePulse?

**LifePulse** is a **real, genuine, and 100% free** emergency blood donation network that directly connects patients in critical medical emergencies with **verified voluntary donors** and **licensed blood banks** — with zero commercialization, full donor privacy protection, and no middlemen.

> 🛡️ Built in compliance with **WHO Safety Standards** and **National Blood Transfusion Guidelines**
> 💯 **Zero commercial activity** — Blood selling or buying is strictly prohibited by law

## ✨ Core Features

<details open>
<summary><b>🚨 Live Hospital Emergency SOS Feed</b></summary>

- **3-tier urgency system** — `CRITICAL` (<2hrs) | `HIGH` (<24hrs) | `PLANNED`
- Shows verified **hospital name, ward/bed, attending doctor, case/IPD number**
- **Visual unit fulfillment progress bar** — needed vs confirmed units
- One-click **WhatsApp SOS broadcast** with pre-formatted medical alert
- **Direct dialer** to patient attendant's verified mobile number
- Post new emergency requests with **authenticity affirmation protocol**

</details>

<details open>
<summary><b>🔍 Verified Voluntary Donor Registry</b></summary>

- Filter by **blood group** (all 8 types), **city**, and **availability status**
- **Government ID Verified** and **Hospital Donor Verified** badges
- Tiered donor levels: `Bronze Supporter` → `Silver LifeSaver` → `Gold Guardian` → `Platinum Champion`
- **Privacy Phone Masking** — prevents spam, routes requests via automated verified prompts
- WhatsApp quick-contact integration

</details>

<details open>
<summary><b>🩺 WHO-Compliant Medical Eligibility Screening</b></summary>

- Interactive **8-point clinical safety checklist** before every registration
- Checks: Age (18–65) · Weight (≥50kg) · Hemoglobin (≥12.5 g/dL) · No tattoos/piercings (6 months) · No surgery (6 months) · No infection/antibiotics (14 days) · Alcohol-free (24hrs) · 90-day donation interval
- Instant eligibility **PASS / DEFERRED verdict** shown in real-time

</details>

<details open>
<summary><b>🏥 Live Blood Bank Inventory Tracker</b></summary>

- **Real-time unit count** per all 8 blood groups across licensed blood centers
- Color-coded stock badges: 🔴 **Critical** (≤3 units) · 🟡 **Low** (4–10 units) · 🟢 **Adequate** (>10 units)
- Tracks: SDP Apheresis Platelets · Cryoprecipitate · 24x7 emergency blood transport
- Displays verified **government license numbers** for every center

</details>

<details open>
<summary><b>🧬 Interactive Blood Compatibility Matrix</b></summary>

- Select any blood group → instantly see **who you can give to** and **who you can receive from**
- Highlights **Universal Donor (O-)** and **Universal Recipient (AB+)**
- The 4 stages of a whole blood donation explained
- Scientific **Myths vs Facts** guide to remove donation fears

</details>

<details open>
<summary><b>🪪 Digital Verified Blood Donor Card</b></summary>

- Generates an official **printable digital credential** with unique `LP-DNR-XXXX` ID
- Blood group badge · Verification seal · Donor level · QR scan code
- One-click **Print / Save as PDF** support
- Shareable digital card format for WhatsApp and social media

</details>

## ⚙️ Getting Started

```bash
# 1️⃣ Clone the repository
git clone https://github.com/Naina137/-blood-donation-app.git
cd -blood-donation-app

# 2️⃣ Install dependencies
npm install

# 3️⃣ Start development server
npm run dev
# 🌐 Open http://localhost:5173

# 4️⃣ Build for production
npm run build
```
