## 💡 LifePulse क्या है?

**LifePulse** एक **100% free, genuine** और **non-profit** blood donation & emergency platform है जो:

- 🚨 Critical hospital cases को **verified voluntary donors** से connect करता है
- 🏥 Licensed blood banks की **real-time stock** track करता है
- 🩺 **WHO-compliant** medical eligibility screening करता है
- 🛡️ **Zero commercialization** — blood buying/selling strictly prohibited

## 🚀 Run Locally

```bash
# Clone the repo
git clone https://github.com/Naina137/-blood-donation-app.git

# Install dependencies
cd -blood-donation-app
npm install

# Start dev server
npm run dev
# 🌐 Open http://localhost:5173
```
