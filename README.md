## 🌟 What is LifePulse?

**LifePulse** is a **real, genuine, 100% free** blood donation and emergency SOS platform that directly connects patients in critical medical emergencies with **verified voluntary donors** and **licensed blood banks** — with **zero commercialization** and **full donor privacy protection**.

Built with modern web technology, LifePulse serves as a **trusted digital bridge** for:
- 🏥 Hospital emergency wards and ICU blood coordinators
- 👨‍👩‍👧 Patient family attendants in crisis situations
- 🩸 Voluntary blood donors willing to save lives
- 🏦 Licensed blood banks tracking real-time stock

## 🚀 Getting Started (Local Development)

### Prerequisites
![Node.js](https://img.shields.io/badge/Node.js-v18+-339933?style=flat-square&logo=node.js)
![npm](https://img.shields.io/badge/npm-v9+-CB3837?style=flat-square&logo=npm)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Naina137/-blood-donation-app.git

# 2. Navigate into the project
cd -blood-donation-app

# 3. Install all dependencies
npm install

# 4. Start the development server
npm run dev
```

Open **[http://localhost:5173](http://localhost:5173)** in your browser 🎉

### Build for Production

```bash
npm run build
```
